# chsi.info 独立静态演示站

本仓库将原有手机界面演示迁出 ChatGPT Sites 托管，提供独立的静态访问路径。网页内容、头像和资料用于界面演示，页脚保留清晰可读的“非官方演示 · 资料虚构”，不提供官方学籍验证或账号服务。

## 运行

所有资源已本地化，无需构建或安装依赖。可用任意静态服务器预览根目录。入口使用 `#/home`、`#/dashboard`、`#/education`、`#/student`、`#/reports`、`#/report` 等路由。

## 发布与验收

阶段总追踪：#1（独立托管与无VPN访问修复）。唯一功能：#2（独立静态托管与域名迁移）。先发布测试分支并验证用户原网络，再切换正式域名；测试站部署成功不代表无VPN故障已修复。

原始真实资料、录屏、截图、访问凭证及旧证件照不在本仓库中。登录输入禁用，仅可进入演示。下载按钮使用浏览器打印。
